SIIED BI Manual

Manual de uso de SIIED BI

Guía para crear dashboards estadísticos con Apache Superset integrado al SIIED.

1 ¿Qué es SIIED BI?

SIIED BI integra Apache Superset al SIIED para permitir la creación de dashboards interactivos sin necesidad de licencias de herramientas propietarias como Looker Studio o Power BI.

Con este módulo puede:

  • Crear tableros de control estadístico con gráficos, tablas y filtros interactivos.
  • Usar datos del SIIED (indicadores, series, conjuntos de datos, catálogos de consulta) directamente como fuente de datos.
  • Subir archivos CSV propios como datasets adicionales.
  • Obtener links de acceso para compartir tableros con el equipo.

2 Acceso y permisos

Pueden acceder a SIIED BI:

  • Analistas: usuarios con rol de analista del módulo Analítica e IA.
  • Administradores (staff): acceso total.

Acceda desde /analitica/superset/ o desde el módulo Analítica e IA del portal. Al asignar el rol analista a un usuario en el admin, su cuenta de Superset se crea automáticamente con la contraseña compartida del sistema.

3 Panel principal

Al ingresar verá el panel principal con:

  • Estado de Superset: indicador de si el servicio está en línea.
  • Contadores: tableros creados, datasets disponibles, conjuntos de datos del SIIED.
  • Grid de tableros: tarjetas con thumbnail, título, estado y acceso rápido.

Desde aquí puede crear tableros, subir CSV o abrir Superset directamente.

4 Los datasets: las fuentes de datos

En Superset todo gráfico nace de un dataset (una tabla consultable). El SIIED le entrega cuatro familias de datasets, identificables por su nombre:

Dataset Origen SIIED Contenido
vista_indicadores_datos Indicadores y sus datos Vista plana global dominio → tema → subtema → indicador → año → valor, con desagregaciones geográfica y temática. Útil para análisis comparativos entre temas.
dominio_<id>_<nombre> Indicadores por dominio La misma vista plana pero filtrada a un solo dominio — más liviana para trabajar un área específica sin perder la taxonomía. Se crean con Sincronizar SIIED.
conjunto_<id>_<nombre> Conjuntos de Datos Cada ConjuntoDatos del SIIED (archivos microdata) subido como tabla. Se crean con Sincronizar SIIED.
catalogo_<id>_<nombre> Catálogos de consulta Nomencladores, directorios, inventarios y fichas territoriales del catálogo de consulta. Se crean con Sincronizar SIIED.
ficed_* Medición FICED Capacidad estadística por organismo: formularios (puntajes por período), recursos_humanos (equipos) y dimensiones (puntaje por dimensión B/C/D/E para radar o barras). Vistas en vivo.
taller_* Taller de gestión de datos Seguimiento del taller: inscripciones, retos, fuentes (con conteos de variables/etiquetas), evaluaciones de seguridad y avances de formalización. Vistas en vivo.
satisf_* Encuestas de satisfacción Respuestas completas del formulario oficial: respuestas (6 calificaciones + promedio) y dimensiones (una fila por dimensión para distribuciones). Vistas en vivo.
nombre libre Archivos propios CSV/Excel que usted sube manualmente desde Subir CSV.

Sincronizar SIIED

El botón "Sincronizar SIIED" del panel convierte automáticamente todos los Conjuntos de Datos y Catálogos de Consulta activos en datasets de Superset. Ejecútelo cuando cargue o actualice conjuntos o catálogos — cada re-sincronización reemplaza la tabla con los datos más recientes.

Columnas clave de vista_indicadores_datos: dominio, tema, subtema, indicador, codigo_indicador, anio, fecha_dato, valor_dato, desagregacion_geografica, desagregacion_tematica.

5 Explorar un dataset

Antes de armar un tablero, explore los datos con la vista Explore:

  1. Vaya a "Explorar SIIED BI". En el menú superior elija Datasets (o Charts → + Chart).
  2. Seleccione el dataset a explorar — por ejemplo vista_indicadores_datos o un catalogo_*.
  3. En el panel izquierdo elija el tipo de gráfico (Table, Bar Chart, Line Chart, Pie...).
  4. Arrastre columnas al constructor:
    • Dimensión / eje X: anio, dominio, tema o la columna territorial del catálogo.
    • Métrica: SUM(valor_dato), AVG(valor_dato) o COUNT(*) para conteos.
    • Agrupar por: desagregacion_geografica o desagregacion_tematica para comparar segmentos.
    • Filtros: indicador = '...', rango de anio, etc.
  5. Presione "Update chart" para previsualizar. Ajuste y repita.
  6. Cuando el gráfico sirva, use "Save" → asígnelo a un dashboard (nuevo o existente).

Para análisis ad-hoc con SQL use SQL Lab (menú SQL → SQL Lab): la base de datos SIIED - Indicadores expone todas las tablas del sistema.

6 Subir un CSV propio

Para crear un dataset a partir de un archivo propio:

  1. Vaya a "Subir CSV" desde el encabezado del panel.
  2. Elija la fuente:
    • Archivo: suba un .csv, .tsv, .xlsx o .xls desde su equipo.
    • Conjunto de Datos SIIED: seleccione un conjunto ya cargado (el nombre se genera solo).
  3. Opcionalmente asigne un nombre de tabla (snake_case, ej: empleo_informal_2025). Si lo deja vacío se genera desde el archivo.
  4. Haga clic en "Subir a SIIED BI".

El dataset quedará disponible inmediatamente en Superset para crear visualizaciones.

7 Crear un tablero

  1. Haga clic en "Crear Tablero". Se abrirá SIIED BI (Apache Superset) embebido.
  2. En Superset, cree un nuevo dashboard y agréguele gráficos (charts).
  3. Para cada gráfico, seleccione el dataset (tabla del SIIED o CSV subido).
  4. Configure el tipo de visualización: barras, líneas, tablas, mapas, etc.
  5. Una vez satisfecho, publique el dashboard.

El tablero aparecerá automáticamente en la lista del panel de Tableros del SIIED.

8 Compartir y embeber tableros

Cada tablero tiene:

  • Link directo: URL compartible que lleva al dashboard en Superset.
  • Vista embebida: si está habilitada, el dashboard se muestra dentro del SIIED sin salir del portal.
  • Botón "Abrir en ventana": abre el dashboard directamente en Superset.

Para habilitar la vista embebida, un administrador debe activar el modo "Embedded" en el dashboard desde Superset.

9 Consejos y buenas prácticas

  • Use nombres descriptivos para tableros y datasets (incluya el año y tema).
  • Prefiera vista_indicadores_datos y los datasets sincronizados (conjunto_*, catalogo_*) en lugar de CSV sueltos: los datos se actualizan con el sistema.
  • Re-ejecute Sincronizar SIIED tras cargar conjuntos o catálogos nuevos.
  • Publique solo tableros finalizados — los borradores son visibles solo para editores.
  • Aproveche los filtros interactivos de Superset para que los usuarios puedan explorar los datos.
  • Para exploración ad-hoc con lenguaje natural, use Consulta y Tableros (Don Datico).
