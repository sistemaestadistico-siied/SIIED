Instrucciones para Carga de Conjunto de datos

Guía completa para preparar y cargar archivos de conjunto de datos

Volver al Formulario

1 ¿Qué es Conjunto de datos?

La conjunto de datos es un conjunto de datos a nivel de observación individual que contiene información detallada sobre variables específicas. A diferencia de los datos agregados, el conjunto de datos permite análisis más profundos y la extracción de múltiples indicadores desde una única fuente.

Importante: Un archivo de conjunto de datos puede alimentar uno o varios indicadaores.

2 Formatos Aceptados

El sistema acepta dos formatos de conjunto de datos según la estructura de sus datos:

Formato Largo (Desagregaciones en Columnas)

Las desagregaciones temáticas se representan como columnas. Cada fila es una observación con sus desagregaciones.

Año Grupos de edad Nacimientos Poblacion_Mujeres
2022 15-19 5500 93000
2022 20-24 7800 91000
2022 25-29 6500 89000

Ideal para: Datos con pocas desagregaciones o datos tabulares simples.

Formato Ancho (Desagregaciones en Encabezados)

Las desagregaciones temáticas se representan en los encabezados de columnas, separadas por guión bajo (_).

AÑO ÁREA GEOGRÁFICA Hombres_0 Hombres_1 Mujeres_0 Mujeres_1
2022 Cabecera Municipal 17722 17603 16677 16595
2023 Cabecera Municipal 17937 17748 16940 16795

Ideal para: Datos demográficos, tablas cruzadas y múltiples desagregaciones.

3 Estructura Requerida

Columna de Fecha/Año (Obligatoria)

El encabezado puede ser: Año, AÑO, año, Fecha, fecha, FECHA

Formato: número (2024) o fecha (2024-01-15)

Desagregaciones Geográficas (Opcional)

El encabezado debe tener el nombre del dominio geográfico.

Ejemplos: "Barrios y Veredas", "Comunas y Corregimientos", "Área Geográfica"

Desagregaciones Temáticas (Opcional)

  • Formato Largo: En columnas con nombre del dominio (ej: "Grupos de edad")
  • Formato Ancho: En encabezados separados por guión bajo (ej: Hombres_0, Mujeres_15-19)

Columnas de Valores

Las columnas numéricas que contienen los valores de las variables.

Use punto (.) como separador decimal, no comas.

4 Archivo de Metadata de Variables

Además del archivo de conjunto de datos, debe proporcionar un archivo Excel con la metadata de las variables que describe cada columna del archivo de conjunto de datos.

Codigo_Indicador Nombre_Indicador Codigo_Variable Nombre_Variable Definicion_Conceptual
ICET_ECO_FIN_ING_01 Presupuesto municipal V1 Ingresos totales Total de ingresos del municipio
ICET_ECO_FIN_ING_01 Presupuesto municipal V2 Ingresos tributarios Ingresos por impuestos

Importante: Puede descargar la plantilla de metadata de variables desde el botón en el formulario de carga.

5 Proceso de Carga Paso a Paso

Opción A: Crear Nuevo Conjunto de Conjunto de datos

1
Identifique los IDs de los indicadores

Determine qué indicadores se alimentarán de este archivo de conjunto de datos (1-6 indicadores). ¿Dónde encontrar los IDs? Ve a "Reportes de Indicadores" - Tabla completa con IDs numéricos.

2
Seleccione "Crear nuevo conjunto"

En el formulario, elija la opción para crear un nuevo conjunto de conjunto de datos.

3
Ingrese los IDs de indicadores

Escriba los IDs separados por comas (ej: 45, 67, 89, 102).

4
Suba los archivos

Adjunte ambos archivos Excel (conjuntos de datos y metadata de variables).

5
Envíe y verifique

Envíe el formulario y recibirá un código de evidencia. Puede verificar el estado en el historial.

Opción B: Actualizar Conjunto de datos Existente

1
Seleccione "Actualizar existente"

En el formulario, elija la opción para actualizar un conjunto existente.

2
Elija el conjunto a actualizar

Seleccione de la lista el conjunto de conjunto de datos que desea actualizar.

3
Suba los nuevos archivos

Adjunte los archivos actualizados (reemplazarán los existentes).

4
Envíe y verifique

Envíe el formulario y recibirá un código de evidencia.

6 Recomendaciones y Buenas Prácticas

Hacer

  • ✓ Use nombres de columnas descriptivos y claros
  • ✓ Verifique que no haya celdas vacías en columnas clave
  • ✓ Use punto (.) como separador decimal
  • ✓ Mantenga consistencia en los formatos de fecha
  • ✓ Documente bien las variables en el archivo de metadata
  • ✓ Para crear nueva conjunto de datos, tenga listos los IDs de indicadores
  • ✓ Para actualizar, seleccione el conjunto correcto de la lista

Evitar

  • ✗ No use caracteres especiales en nombres de columnas
  • ✗ No mezcle formatos de fecha en la misma columna
  • ✗ No use coma (,) como separador decimal
  • ✗ No deje filas completamente vacías en medio de los datos
  • ✗ No modifique la estructura después de cargar
  • ✗ No cree múltiples conjunto de datos para el mismo indicador
  • ✗ No use IDs de indicadores incorrectos o inventados
