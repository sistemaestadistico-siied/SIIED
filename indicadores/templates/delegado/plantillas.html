Plantillas y formatos oficiales

Descarga las plantillas Excel que debes usar para entregar tus datos. No uses otros formatos.

Regla fundamental: usa siempre estas plantillas oficiales

  • No cambies los nombres de las columnas.
  • No agregues hojas adicionales al archivo.
  • No combines celdas ni apliques formatos especiales.
  • Los años deben ser valores numéricos (ej: 2024).
  • Los números no deben llevar puntos de miles ni símbolos de moneda.
  • Usa punto (.) como separador decimal, no coma.

Codigo_Indicador — Código oficial del indicador (ej: ICET_SAL_DEM_MOR_02). El equipo SIIED te lo indicará.

Nombre_Indicador — Nombre completo del indicador.

Año — Año de la medición como número entero (2022, 2023…).

Desagregacion_Geografica — Nombre del área geográfica (ej: Comuna 1, Barrio Centro). Déjalo vacío si no aplica.

Desagregacion_Tematica_1 — Primera categoría de análisis (ej: Hombre, Mujer). Déjalo vacío si no aplica.

Desagregacion_Tematica_2 — Segunda categoría (ej: 0-1 años, 2-5 años). Déjalo vacío si no aplica.

Valor — Valor numérico. Sin texto, sin unidades, sin % ni $. Usa punto decimal.

Archivos para conjuntos de datos

Para cargar conjuntos de datos debes subir dos archivos: los datos (tabla de conjuntos de datos) y la metadata de sus variables.

🗃️

Archivo 1 de 2: Conjuntos de datos

Si aplica

Tabla con los datos fuente del indicador. El sistema acepta dos formatos: Largo y Ancho. La plantilla incluye ambos como hojas separadas.

¿Cuándo usar cada formato?

Formato Largo: úsalo cuando tus datos tengan pocas categorías de desagregación o cuando ya existen en formato de tabla larga. La columna Año es obligatoria; el encabezado de desagregación debe coincidir exactamente con el nombre del dominio configurado en el sistema.

Formato Ancho: úsalo para datos demográficos o tablas cruzadas con muchas combinaciones. Las columnas de datos van en el patrón Categoría_Índice (ej: Hombres_0). La columna AÑO es obligatoria.

Ambos formatos deben usar punto decimal, sin símbolos de moneda ni texto en columnas numéricas.
