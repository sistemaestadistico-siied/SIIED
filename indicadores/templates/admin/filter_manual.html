🔍 Manual de Filtros para Extracción de Datos

Los filtros permiten seleccionar subconjuntos específicos de datos del CSV antes de aplicar las fórmulas de cálculo.

🔧 Formato JSON de Filtros

Formato básico:

{"nombre_columna": "valor_a_filtrar"}

Los filtros deben estar en formato JSON válido con comillas dobles.

📋 Tipos de Filtros Soportados

1. Filtro de Igualdad Exacta
{"Ciudad": "Santiago de Cali"}

Solo procesa filas donde la columna "Ciudad" sea exactamente "Santiago de Cali"

2. Filtro por Área Geográfica
{"ÁREA GEOGRÁFICA": "Cabecera Municipal"}

Filtra solo datos del área urbana principal

3. Filtro por Año
{"AÑO": "2023"}

Procesa únicamente datos del año 2023

4. Filtros Múltiples (AND)
{ "Ciudad": "Santiago de Cali", "ÁREA GEOGRÁFICA": "Total", "AÑO": "2023" }

Todas las condiciones deben cumplirse simultáneamente

5. Filtro por Tipo de Dato
{"Tipo": "Nacimientos"}

Filtra por categoría específica de datos

⚠️ Cómo Funcionan los Filtros

Los filtros se aplican ANTES del procesamiento cartesiano:

  • Se cargan todas las filas del CSV
  • Se aplican los filtros para seleccionar solo las filas que cumplen las condiciones
  • Solo las filas filtradas se procesan con el algoritmo cartesiano
  • Las fórmulas se evalúan únicamente sobre los datos filtrados

📊 Ejemplos Prácticos por Caso de Uso

Ejemplo 1: Población Solo Urbana

Objetivo: Calcular indicadores solo para el área urbana

Filtro: {"ÁREA GEOGRÁFICA": "Cabecera Municipal"}

Resultado: Solo se procesan filas con datos urbanos

Ejemplo 2: Datos de un Año Específico

Objetivo: Análisis retrospectivo del año 2020

Filtro: {"AÑO": "2020"}

Resultado: Solo datos del 2020, ignorando otros años

Ejemplo 3: Filtro Combinado Complejo

Objetivo: Nacimientos urbanos en Cali durante 2023

Filtro:

{ "Ciudad": "Santiago de Cali", "ÁREA GEOGRÁFICA": "Cabecera Municipal", "AÑO": "2023", "Tipo_Evento": "Nacimiento" }

Resultado: Solo nacimientos urbanos de Cali en 2023

Ejemplo 4: Filtro por Categoría de Establecimiento

Objetivo: Solo datos de hospitales públicos

Filtro: {"Tipo_Establecimiento": "Hospital", "Sector": "Público"}

Resultado: Excluye clínicas privadas y otros tipos

🚨 Casos Especiales y Consideraciones

Sin Filtros (Procesar Todo)

Dejar vacío o usar: {}

Procesa todas las filas del CSV sin restricciones

Valores con Espacios o Caracteres Especiales

Correcto: {"ÁREA GEOGRÁFICA": "Centros Poblados y Rural Disperso"}

Usar comillas dobles y el texto exacto como aparece en el CSV

Filtros Sensibles a Mayúsculas

Importante: "Cali" ≠ "CALI" ≠ "cali"

Usar exactamente el mismo formato que aparece en el archivo CSV

❌ Errores Comunes

❌ JSON Inválido

Incorrecto: {'Ciudad': 'Cali'} (comillas simples)

Incorrecto: {Ciudad: "Cali"} (clave sin comillas)

Correcto: {"Ciudad": "Cali"}

⚠️ Nombres de Columnas Incorrectos

Error: Usar nombres que no existen en el CSV

Solución: Verificar los nombres exactos en el archivo CSV original

⚠️ Filtros Demasiado Restrictivos

Problema: Filtros que no coinciden con ninguna fila

Resultado: No se generan datos para el indicador

💡 Consejos de Uso

  • Empezar sin filtros: Procesa todo primero para entender la estructura
  • Validar JSON: Usa herramientas online para verificar la sintaxis JSON
  • Probar incrementalmente: Añade filtros uno por uno para identificar problemas
  • Revisar el CSV: Abre el archivo en Excel/LibreOffice para ver los valores exactos
  • Usar el diagnóstico: El botón "Diagnosticar" muestra qué filas coinciden con los filtros
  • Logs detallados: Usa verbosity alta para ver qué filtros se aplican
  • Filtros geográficos: Muy útiles para indicadores por zona específica
  • Filtros temporales: Esenciales para análisis de series de tiempo

🔧 Herramientas de Depuración

Comando de Diagnóstico

Usa el botón "Diagnosticar" en la regla para ver:

  • Cuántas filas coinciden con los filtros
  • Ejemplos de filas filtradas
  • Columnas disponibles en el CSV
  • Valores únicos por columna
