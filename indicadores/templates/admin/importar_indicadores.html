📋 Formato del Archivo CSV

Columnas requeridas:

  • nombre - Nombre del indicador (requerido)
  • subtema - ID o nombre del subtema (requerido)

Columnas opcionales:

  • descripcion - Descripción del indicador
  • definicion_operacional - Definición operacional
  • unidad_medida - Unidad de medida (ej: "Porcentaje", "Número")
  • fuente_datos - Fuente de los datos
  • entidad_responsable - Entidad responsable del indicador
  • periodicidad - Periodicidad de actualización
  • fecha_publicacion_metadatos - Fecha de publicación de metadatos MSD (formato: YYYY-MM-DD)
  • notas - Notas adicionales
  • operacion - ID o nombre de la operación estadística
  • activo - True/False, 1/0, Si/No
  • orden - Número para ordenar (entero)
  • mostrar_mapa - True/False, 1/0, Si/No
  • dominios_tematicos - IDs o nombres separados por coma
  • dominios_geograficos - IDs o nombres separados por coma

Ejemplo de archivo CSV:

nombre,subtema,descripcion,unidad_medida,activo,orden
"Tasa de Desempleo",1,"Porcentaje de población desempleada","Porcentaje",True,1
"Población Total",2,"Número total de habitantes","Número",True,2
