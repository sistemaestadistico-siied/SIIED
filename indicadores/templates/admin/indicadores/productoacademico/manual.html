Manual de Productos Académicos

Guía operativa para la creación y gestión de papers y productos estadísticos integrados

1. ¿Qué es un Producto Académico?

Un Producto Académico es un documento enriquecido que documenta el proceso de producción de indicadores estadísticos. Existen dos modos de visualización:

  • Paper académico clásico: sidebar con navegación por secciones, ideal para documentos metodológicos y papers de investigación.
  • Producto estadístico integrado: layout tipo INEGI con pestañas (Presentación, Resultados, Documentación, Tabulados, etc.), ideal para censos, encuestas y operaciones estadísticas.
Consejo: Use "Producto estadístico" cuando el objetivo es presentar datos al público general. Use "Paper clásico" cuando el objetivo es documentar metodología para otros investigadores.

2. Tipos de sección y bloques de contenido

Cada producto se compone de secciones. Cada sección tiene un tipo de sección (Introducción, Resultados, etc.) y un tipo de bloque (texto, gráfico, mapa, etc.).

3. Cómo crear un producto estadístico tipo INEGI

  1. Cree el Producto Académico y marque "Es producto estadístico".
  2. Complete los metadatos: operación estadística, cobertura geográfica, periodo de referencia.
  3. Vincule Temas relacionados (aparecerán como chips debajo de las pestañas).
  4. Cree las secciones en el orden deseado usando número de orden (1, 2, 3...).
  5. Para la Presentación, use tipo de sección Resumen o Introducción. Estas aparecerán antes de las pestañas.
  6. Para Resultados, use tipo de sección Resultados con bloques de gráfico, tabla o KPI.
Importante: El modo estadístico ignora las secciones de tipo Resumen e Introducción al construir las pestañas; las muestra como presentación colapsable encima de las pestañas.

4. Subnúmeros y sub-pestañas

El campo Subnúmero permite agrupar secciones dentro de una misma pestaña. Use la notación X.Y:

Sección 4.1 → Población total
Sección 4.2 → Indicadores sociodemográficos
Sección 4.3 → Vivienda

En el modo estadístico, la pestaña Resultados mostrará sub-pestañas: Población total | Indicadores sociodemográficos | Vivienda.

Consejo: Use subnúmeros solo cuando una pestaña tenga más de 3 secciones. Si hay 2 o menos, mantenga subnúmero vacío y el contenido aparecerá directamente en la pestaña.

5. Configuración de gráficos (JSON)

El campo Configuración del gráfico o mapa acepta un objeto JSON para personalizar la visualización:

{
  "tipo": "barras",            // barras | lineas | piramide | pastel
  "anio_default": 2024,      // Año preseleccionado en mapas/tablas
  "mostrar_desagregaciones": true,
  "tipo_mapa": "choropleth"  // Solo para bloques de tipo mapa
}

Si deja el campo vacío, el sistema usa valores por defecto.

5.5 Bloques especiales y multimedia

Visor comparativo de indicadores

Permite comparar varios indicadores en un mismo gráfico de líneas y una tabla cruzada por año.

  1. Cree una sección con tipo de bloque Visor comparativo de indicadores.
  2. En el campo Indicadores preseleccionados (M2M), seleccione 2 a 5 indicadores que compartan la misma unidad o escala.
  3. El sistema genera automáticamente el gráfico comparativo + tabla de años cruzados debajo del gráfico.

Tabla dinámica de conjunto de datos

Diferente de la "Tabla de muestra de conjunto de datos" (que es estática), esta tabla carga hasta 1,000 registros de el conjunto de datos vinculada. Úsela cuando necesite mostrar el universo completo de datos crudos.

Z-Index: El contenedor de la tabla dinámica usa position:relative; z-index:1; para evitar que los menús desplegables de los tabs la oculten.

Video embebido

Solo pegue la URL completa del video en el campo URL de video. Soporta:

  • YouTube: https://www.youtube.com/watch?v=ABC123 o https://youtu.be/ABC123
  • Vimeo: https://vimeo.com/123456789

Galería, Carrusel e Infografía

Los tres bloques usan las Imágenes de sección (inline, en la parte inferior del formulario de la sección). Al agregar imágenes, seleccione el Tipo de uso según el bloque que vaya a usar:

  • Galería: grid de imágenes con leyendas.
  • Carrusel: slider con flechas y transiciones.
  • Infografía: imagen a ancho completo con pie de foto debajo.
Consejo: Puede agregar imágenes a una sección sin importar el tipo de bloque, pero solo se mostrarán si el bloque es Galería, Carrusel o Infografía.

Acordeón / Preguntas frecuentes

Use el campo Acordeón items con un array JSON:

[
  {"titulo": "¿Qué es la ENCV?", "contenido": "

La Encuesta Nacional de Calidad de Vida...

"},
  {"titulo": "¿Cómo se calcula el índice?", "contenido": "

Se ponderan las dimensiones...

"}
]

Descarga de archivos

Agregue archivos en la sección mediante el inline Archivos de sección. Puede personalizar el icono con clases de FontAwesome (ej: fas fa-file-pdf, fas fa-file-excel).

Fórmulas / LaTeX

Escriba la fórmula en el campo Contenido usando sintaxis LaTeX. El sistema carga MathJax automáticamente.

$$\\frac{\\sum_{i=1}^{n} x_i}{n}$$

6. Flujo de publicación

EstadoVisible al públicoAcción
BorradorNoEdición libre por el autor
En revisiónNo (solo staff con preview)Revisión editorial y validación técnica
PublicadoSíVisible en el catálogo público
Preview: Los usuarios staff pueden previsualizar productos en estado Borrador o En revisión usando el botón "Ver en sitio" del admin. Aparecerá una insignia ámbar en la esquina superior derecha.

7. Checklist antes de publicar

  • ¿Todas las secciones tienen número de orden único y secuencial?
  • ¿Los bloques de gráfico, mapa, tabla, ficha o KPI tienen un indicador vinculado?
  • ¿Los bloques de conjunto de datos (estática o dinámica) tienen una conjunto de datos vinculada?
  • ¿Los bloques de documento tienen un documento de infraestructura con archivo PDF o Word?
  • ¿El campo Configuración del gráfico es JSON válido (si se usó)?
  • ¿En modo estadístico, hay al menos una sección de tipo Resumen o Introducción?
  • ¿Los temas relacionados están vinculados (para mostrar chips de navegación)?
  • ¿El visor comparativo tiene al menos 2 indicadores preseleccionados?
  • ¿El video embebido tiene una URL válida de YouTube o Vimeo?
  • ¿Las imágenes de galería, carrusel o infografía tienen el tipo de uso correcto?
  • ¿El acordeón tiene un JSON válido con al menos un item?
  • ¿Los archivos de descarga tienen un nombre visible y un icono de FontAwesome válido?
