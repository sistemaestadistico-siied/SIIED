📋 Manual de Fórmulas para Extracción de Datos

Las fórmulas permiten calcular valores finales a partir de los datos del CSV usando el algoritmo cartesiano de extracción.

🔧 Tipos de Fórmulas Soportadas

1. Fórmula Simple (valor_celda)
valor_celda

Usa directamente el valor de la columna correspondiente a la combinación de desagregaciones.

2. Operaciones Aritméticas
valor_celda * 100
valor_celda / 1000
valor_celda + 50

Operadores soportados: +, -, *, /, //, %, ** (también ^ para potencia)

3. Referencias a Columnas Específicas
hombres_0_4 + mujeres_0_4
col("Hombres 0-4") + col("Mujeres 0-4")

• Variables sanitizadas: Los nombres de columnas se convierten automáticamente (espacios → _, sin acentos)
• Función col(): Para nombres exactos con espacios o caracteres especiales

4. Funciones Matemáticas
abs(valor_celda)
max(hombres_total, mujeres_total)
round(valor_celda / poblacion_total * 100, 2)

Funciones disponibles: abs, min, max, round, pow

⚠️ Cómo Funciona el Algoritmo Cartesiano

El algoritmo genera automáticamente todas las combinaciones posibles de desagregaciones temáticas:

  • Para cada fila del CSV, identifica las desagregaciones geográficas y temáticas
  • Crea el producto cartesiano de todas las desagregaciones temáticas posibles
  • Para cada combinación, busca la columna correspondiente o calcula el valor
  • Si la combinación incluye "Total", suma las otras desagregaciones del mismo dominio

📊 Ejemplos Prácticos

Ejemplo 1: Datos de Población

CSV: Columnas como "Hombres_0_4", "Mujeres_0_4", "Hombres_5_9", etc.

Fórmula: valor_celda

Resultado: Para la combinación (Hombres, 0-4), usa el valor de "Hombres_0_4"

Ejemplo 2: Tasa por 1000 habitantes

CSV: Columna "Nacimientos" con valores absolutos

Fórmula: valor_celda / poblacion_total * 1000

Resultado: Convierte números absolutos a tasa por mil

Ejemplo 3: Suma de Grupos de Edad

CSV: "Edad_0_14", "Edad_15_64", "Edad_65_mas"

Fórmula: edad_0_14 + edad_15_64 + edad_65_mas

Resultado: Suma grupos para obtener totales por otras desagregaciones

🎯 Casos Especiales

Cálculo Automático de Totales

Cuando una combinación incluye una desagregación "Total", el algoritmo automáticamente suma todas las otras desagregaciones del mismo dominio. No necesitas escribir fórmulas especiales para esto.

Manejo de Rangos de Edad

Si defines rangos en las desagregaciones (ej: 0-4, 5-9), el algoritmo automáticamente suma las columnas que caen dentro de cada rango.

🚫 Restricciones de Seguridad

Por seguridad, las fórmulas NO pueden:

  • Ejecutar código arbitrario o importar módulos
  • Acceder a archivos o bases de datos
  • Usar bucles o estructuras de control complejas
  • Llamar funciones no autorizadas

Solo se permiten: operaciones matemáticas, referencias a columnas y las funciones listadas arriba.

💡 Consejos de Uso

  • Empieza simple: Usa valor_celda para la mayoría de casos
  • Prueba paso a paso: Usa el botón "Procesar Datos" para validar tus fórmulas
  • Revisa los logs: Con verbosity alta (--verbosity=3) puedes ver cómo se evalúan las fórmulas
  • Nombres de columnas: "Hombres 0-4" se convierte en hombres_0_4 automáticamente
  • Para nombres complejos: Usa col("Nombre Exacto") con comillas
  • Valores faltantes: Se tratan como 0 en los cálculos
