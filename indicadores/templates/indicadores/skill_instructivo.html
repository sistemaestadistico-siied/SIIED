¿Qué es esta skill?

Una skill es un paquete de instrucciones (estándar Agent Skills: un directorio con un SKILL.md en frontmatter YAML + guía en Markdown) que le enseña a un agente de IA cuándo y cómo usar una capacidad concreta. La skill siied-api-abierta contiene:

  • El mapa completo de endpoints de la API abierta con sus parámetros.
  • Flujos recomendados: descubrir indicadores → leer ficha → bajar series o filas.
  • Reglas de oro: nunca inventar IDs, paginar con offset, qué hacer si un indicador no tiene series.
  • El caso especial de los indicadores enlazados al catálogo de consulta.
  • Ejemplos curl listos para ejecutar.
  • Canal de soporte y contacto institucional.
Skill vs MCP: el servidor MCP le da a tu IA herramientas listas que ya hablan con el SIIED. La skill le enseña a manejar la API REST directamente — útil si tu cliente no soporta MCP o prefieres que el agente llame los endpoints por sí mismo (con curl, Python, etc.). Son complementarios: puedes usar ambos.

Cómo instalarla

Descarga el SKILL.md y colócalo en el directorio de skills de tu cliente (cada uno lo lee de una carpeta concreta). Estructura final: una carpeta siied-api-abierta/ que contiene el archivo.

Ejemplo de instalación (Claude Code):

mkdir -p ~/.claude/skills/siied-api-abierta
curl -o ~/.claude/skills/siied-api-abierta/SKILL.md \
     {{ skill_url }}
