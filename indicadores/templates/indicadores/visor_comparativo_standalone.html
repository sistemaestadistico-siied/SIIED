Guía Completa del Visor Comparativo

Configuración Básica

  1. 1. Seleccione dominios temáticos usando los filtros
  2. 2. Elija indicadores específicos dentro de cada dominio
  3. 3. Defina el rango de años de análisis
  4. 4. Seleccione desagregaciones geográficas/temáticas
  5. 5. Haga clic en "Agregar indicadores"

Tabla Dinámica WebDataRocks - Funcionalidades Avanzadas

Reorganización de Datos (Drag & Drop)
  • Filas: Arrastre campos al área de filas para agrupar datos verticalmente
  • Columnas: Arrastre campos al área de columnas para crear pivotes horizontales
  • Valores: Arrastre métricas numéricas al área de valores para agregaciones
  • Filtros: Use el área de filtros para aplicar condiciones globales
Agregaciones y Cálculos
  • Suma: Agregación por defecto para valores numéricos
  • Promedio: Haga clic derecho en un campo → "Summarize by" → "Average"
  • Conteo: Útil para contar registros únicos por categoría
  • Min/Max: Para encontrar valores extremos en los datos
  • Campos calculados: Cree nuevas métricas combinando campos existentes
Filtrado Avanzado
  • Filtros de campo: Haga clic en el ícono de filtro junto a cada campo
  • Filtros múltiples: Combine varios filtros para análisis específicos
  • Filtros de rango: Para fechas y valores numéricos (ej: años 2020-2023)
  • Búsqueda rápida: Use la caja de búsqueda en cada filtro
  • Filtros condicionales: Mayor que, menor que, contiene, etc.
Ordenamiento y Jerarquías
  • Ordenamiento: Haga clic en encabezados de columna para ordenar
  • Ordenamiento múltiple: Mantenga Shift + clic para ordenar por varios campos
  • Jerarquías: Agrupe campos relacionados (ej: Año → Mes → Día)
  • Expansión/Colapso: Use +/- para expandir/colapsar grupos
  • Drill-down: Doble clic en valores para profundizar en detalles
Formato Condicional y Visualización
  • Formato condicional: Resalte valores según condiciones (colores, barras)
  • Formato de números: Personalice decimales, separadores, monedas
  • Barras de datos: Visualice magnitudes dentro de las celdas
  • Escalas de color: Mapas de calor para identificar patrones
  • Totales y subtotales: Configure totales personalizados por grupo
Consejos Avanzados para Análisis Comparativo
  • Análisis temporal: Coloque "Año" en columnas e indicadores en filas
  • Comparación geográfica: Use desagregaciones geográficas en filas
  • Análisis multivariado: Combine múltiples indicadores en el área de valores
  • Tendencias: Ordene por año para identificar patrones temporales
  • Benchmarking: Compare indicadores similares usando filtros
  • Detección de outliers: Use formato condicional para valores extremos

Gráficos Integrados

  • Gráficos automáticos: WebDataRocks genera gráficos basados en su configuración de tabla
  • Tipos disponibles: Líneas (tendencias), barras (comparaciones), áreas (composición)
  • Sincronización: Los gráficos se actualizan automáticamente al cambiar la tabla
  • Interactividad: Haga clic en elementos del gráfico para filtrar la tabla
  • Múltiples ejes: Para indicadores con diferentes unidades de medida

Exportación de Resultados

Exportación de Tablas:
  • Excel (.xlsx): Mantiene formato y permite análisis posterior
  • CSV: Para integración con otras herramientas de análisis
  • PDF: Para reportes y presentaciones formales
  • HTML: Para publicación web o correos electrónicos
Exportación de Gráficos:
  • PNG/JPG: Para presentaciones y documentos
  • SVG: Gráficos vectoriales escalables
  • PDF: Para reportes de alta calidad

Consideraciones de Rendimiento

  • Carga paginada: Los datos se cargan en lotes para optimizar rendimiento
  • Filtros inteligentes: Use filtros para reducir el volumen de datos procesados
  • Agregaciones eficientes: Las operaciones se realizan en el cliente para mayor velocidad
  • Caché local: Los datos se almacenan temporalmente para navegación rápida
  • Límites recomendados: Para mejor rendimiento, limite a 5-10 indicadores simultáneos
