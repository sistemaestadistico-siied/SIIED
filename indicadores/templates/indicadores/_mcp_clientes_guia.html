Instalación por cliente

Guía rápida para los clientes MCP más usados. En todos los casos el servidor se llama siied; donde se muestra TU_TOKEN reemplázalo por tu token personal u omítelo para la capa pública.

Claude Desktop (app escritorio)

Settings → Developer → Edit Config, o edita claude_desktop_config.json:

macOS ~/Library/Application Support/Claude/ · Windows %APPDATA%\Claude\ · Linux ~/.config/Claude/

{
  "mcpServers": {
    "siied": {
      "command": "/ruta/del/proyecto/.venv/bin/python",
      "args": ["-m", "indicadores.mcp_stdio_entry"],
      "cwd": "/ruta/del/proyecto",
      "env": { "SIIED_MCP_TOKEN": "TU_TOKEN" }
    }
  }
}

Reinicia la app. Para servidor remoto: Settings → Connectors → agregar conector con la URL {{ mcp_url }}.

ChatGPT (app escritorio / web)

Se configura por interfaz, sin archivo:

  1. Settings → MCP servers → Add server.
  2. Nombre: siied · elige Streamable HTTP y pega la URL {{ mcp_url }} — o STDIO con el comando /ruta/del/proyecto/.venv/bin/python -m indicadores.mcp_stdio_entry (cwd: /ruta/del/proyecto).
  3. Guarda y reinicia.

Con token, añade header Authorization: Bearer TU_TOKEN (HTTP) o la env var SIIED_MCP_TOKEN (stdio). Las acciones de escritura requieren developer mode en planes Business/Enterprise.

Cursor (IDE)

.cursor/mcp.json (proyecto) o ~/.cursor/mcp.json (global):

{
  "mcpServers": {
    "siied": {
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

O local por stdio: "command": "/ruta/del/proyecto/.venv/bin/python", "args": ["-m","indicadores.mcp_stdio_entry"], "cwd": "/ruta/del/proyecto". Soporta ${workspaceFolder} y ${env:VAR}.

VS Code + GitHub Copilot (editor)

.vscode/mcp.json — ojo: la clave es "servers", no mcpServers:

{
  "servers": {
    "siied": {
      "type": "http",
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

Alternativa portable para Copilot: .mcp.json en la raíz o ~/.copilot/mcp-config.json con clave "mcpServers". Para stdio usa "type": "stdio" + command/args/cwd. Pulsa Start sobre el bloque del server.

Gemini CLI (terminal)

~/.gemini/settings.json — para HTTP usa httpUrl (url es SSE):

{
  "mcpServers": {
    "siied": {
      "httpUrl": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

Stdio: "command": "/ruta/del/proyecto/.venv/bin/python", "args": ["-m","indicadores.mcp_stdio_entry"], "cwd": "/ruta/del/proyecto", "env": {"SIIED_MCP_TOKEN":"TU_TOKEN"}. También: gemini mcp add siied -- /ruta/del/proyecto/.venv/bin/python -m indicadores.mcp_stdio_entry. Verifica con /mcp.

Codex CLI (terminal / OpenAI)

~/.codex/config.toml (compartido con ChatGPT desktop):

[mcp_servers.siied]
command = "/ruta/del/proyecto/.venv/bin/python"
args = ["-m", "indicadores.mcp_stdio_entry"]
cwd = "/ruta/del/proyecto"
env = { SIIED_MCP_TOKEN = "TU_TOKEN" }

# o remoto:
# [mcp_servers.siied]
# url = "{{ mcp_url }}"
# http_headers = { Authorization = "Bearer TU_TOKEN" }

O vía CLI: codex mcp add siied -- /ruta/del/proyecto/.venv/bin/python -m indicadores.mcp_stdio_entry. Lista con codex mcp list.

OpenCode (terminal)

opencode.json (proyecto) o ~/.config/opencode/opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "siied": {
      "type": "remote",
      "url": "{{ mcp_url }}",
      "enabled": true,
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

Local: "type": "local", "command": ["/ruta/del/proyecto/.venv/bin/python","-m","indicadores.mcp_stdio_entry"], "cwd": "/ruta/del/proyecto", "environment": {"SIIED_MCP_TOKEN":"TU_TOKEN"}.
