Guía de Uso - Tabla Dinámica

Hoja de Cálculo Interactiva (Univer)

🚀 Cómo empezar:

  1. Haga clic en "Cargar Hoja de Cálculo" para inicializar Univer
  2. Los datos se cargarán automáticamente en una hoja editable
  3. Use scroll, teclado y barra de herramientas para explorar y editar

📊 Funcionalidades principales:

  • Edición directa: Modifique celdas con doble clic
  • Fórmulas básicas: Funciones como SUM, AVERAGE, COUNT
  • Ordenamiento y filtros: Desde el menú contextual
  • Formato: Negrita, color de fondo, alineación
  • Exportación: Descargue datos originales como Excel o CSV

🎛️ Funciones disponibles:

  • Redimensionamiento de filas y columnas
  • Copiar y pegar entre celdas
  • Deshacer y rehacer cambios (Ctrl+Z/Ctrl+Y)
  • Selección múltiple de celdas
  • Navegación con teclado (flechas, Tab, Enter)

💡 Consejos útiles:

  • • Use la hoja de cálculo para editar y analizar los datos
  • • Descargue los datos originales usando los botones superiores
  • • Haga doble clic en una celda para editarla
  • • Use Ctrl+Z/Ctrl+Y para deshacer/rehacer cambios
  • • Seleccione múltiples celdas arrastrando el mouse
