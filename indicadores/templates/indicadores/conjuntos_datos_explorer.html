Manual del Explorador de Conjuntos de datos

Aprende a utilizar todas las capacidades de la plataforma

📊 Búsqueda y Filtrado

  • • Búsqueda global: Utiliza la barra de búsqueda superior para encontrar dominios, temas, subtemas y datasets simultáneamente.
  • • Búsqueda de datasets: Usa el buscador específico de datasets para encontrar conjuntos de datos por nombre o descripción, con resultados independientes.
  • • Navegación por categorías: Explora dominios → temas → subtemas para descubrir datasets organizados jerárquicamente.

📥 Exportación de Datos

  • • Exporta conjuntos de datos completos en formato CSV o Excel.
  • • Selecciona columnas específicas antes de exportar.
  • • Obtén enlaces compartibles para tus exportaciones.

🔍 Visualización de Datos

  • • Genera gráficos interactivos con solo unos clics.
  • • Personaliza colores, etiquetas y tipos de gráfico.
  • • Incrusta visualizaciones en informes o presentaciones.

📝 Análisis con JupyterLite

  • • Ejecuta código Python directamente en tu navegador sin necesidad de configuración.
  • •
    Almacenamiento persistente: Tu instancia de JupyterLite guarda automáticamente tus notebooks y archivos en el almacenamiento local de tu navegador. Esto significa que:
    • • Toda tu información se conserva entre sesiones
    • • No necesitas iniciar sesión
    • • Los datos persisten mientras uses el mismo navegador y dispositivo
  • •
    Para trabajar con datos:
    • 1. Descarga los datos en formato CSV desde el explorador
    • 2. En JupyterLite, sube el archivo CSV usando el ícono de carga
    • 3. Usa Pandas para cargar y analizar tus datos
  • •
    Bibliotecas disponibles: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, y más. Para instalar paquetes adicionales, usa: %pip install nombre_del_paquete

💡 Consejos Rápidos

  • • Usa comillas para buscar frases exactas.
  • • Haz clic derecho en las tablas para más opciones.
  • • Mantén presionada la tecla Ctrl (o Cmd) para seleccionar múltiples filtros.
