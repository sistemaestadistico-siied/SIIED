¿Qué es el MCP del SIIED?

El Model Context Protocol (MCP) es un estándar abierto que permite a las aplicaciones de IA usar herramientas externas de forma segura. El servidor MCP del SIIED expone {{ total_tools }} herramientas para que tu asistente consulte el catálogo estadístico distrital —y, si tienes rol asignado, automatice cargas y consultas de validación— sin salir de tu aplicación de escritorio o flujo de agentes.

Consulta abierta

Indicadores, series, conjuntos de datos, catálogos de consulta y estructura dominio-tema-subtema.

Gestión por rol

Recolectores cargan series, conjuntos de datos y metadata — siempre a validación, nada se publica directo.

Validación FICED

Validadores consultan la hoja de vida completa del organismo y el detalle del formulario FICED.

Cómo conectar tu cliente

El servidor ofrece dos transportes. Usa Streamable HTTP si tu cliente acepta una URL remota; usa stdio si el cliente lanza el servidor como proceso local (Claude Desktop, Gemini CLI, etc.).

Opción 1 · Endpoint HTTP remoto

En tu cliente configura un servidor MCP tipo HTTP / streamable:

{
  "mcpServers": {
    "siied": {
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer TU_TOKEN_MCP" }
    }
  }
}

El header Authorization solo es necesario si tienes token de acceso por rol (ver niveles de acceso).

Opción 2 · Proceso local (stdio)

El cliente lanza el servidor él mismo. Ejemplo para Claude Desktop o ~/.gemini/settings.json de Gemini CLI: 

{
  "mcpServers": {
    "siied": {
      "command": "/ruta/del/proyecto/.venv/bin/python",
      "args": ["-m", "indicadores.mcp_stdio_entry"],
      "cwd": "/ruta/del/proyecto",
      "env": { "SIIED_MCP_TOKEN": "TU_TOKEN_MCP" }
    }
  }
}
  • No hace falta mantener ningún servidor corriendo: el cliente lo inicia por sesión.
  • La variable SIIED_MCP_TOKEN es opcional — sin ella la sesión queda en capa pública.

Niveles de acceso

El servidor decide qué herramientas mostrar según tu identidad. Sin token solo ves la capa pública; con token personal, tu rol vigente en el SIIED define las herramientas adicionales. No se comparten credenciales: cada token es personal y todas las llamadas quedan registradas en auditoría.

Nivel Requiere token Herramientas Qué puede hacer
Público No {{ tools_publicos }} Consulta abierta: buscar indicadores, fichas, series, conjuntos de datos, catálogo de consulta, estructura del sistema, satisfacción y documentos.
Recolector Sí +{{ tools_recolector }} Todo lo público + mi_contexto, mis_cargas, estado_carga, plantillas, deconstrucción de tablas y cargas de series/conjuntos/metadata en borrador (pasan a validación).
Validador Sí +{{ tools_validador }} Todo lo público + listar_organismos_ficed, hoja_vida_organismo y consultar_ficed: hoja de vida completa del organismo y detalle FICED (solo lectura).

¿Cuándo se necesita usuario y token?

Sin token (anónimo)

  • Explorar el catálogo público de indicadores y conjuntos.
  • Leer fichas, series y catálogos de consulta.
  • Probar el servidor y evaluar su utilidad.

Con token personal

  • Recolectores: cargar series, conjuntos de datos y metadata de variables.
  • Validadores: consultar hoja de vida y formularios FICED.
  • Los tokens tienen vigencia y se revocan si cambia tu rol o tu acceso.

Solicita tu token MCP

Si eres funcionario de un organismo del Sistema Estadístico y necesitas cargar datos o consultar la hoja de vida/FICED desde tu asistente de IA, solicita tu token personal indicando: nombre, organismo, correo institucional y el uso previsto.

sistemaestadistico@cali.gov.co

¿Prefieres la burbuja?

También puedes enviar tu requerimiento por la burbuja flotante de chat (esquina inferior derecha del sitio). Es el mismo canal de soporte: llega al correo sistemaestadistico@cali.gov.co — indica que la solicitud es para un token MCP y tu organismo.

Notas

  • Transporte HTTP: Streamable HTTP (protocolo MCP 2025-03-26) en {{ mcp_url }}.
  • Transporte stdio: python -m indicadores.mcp_stdio_entry — el cliente lanza el proceso.
  • Todas las llamadas quedan registradas en el log de auditoría (usuario, herramienta, duración, resultado).
  • Las cargas por MCP nunca se publican solas: quedan en estado pendiente hasta validación del SIIED.
  • El token se entrega una sola vez por correo seguro; no lo compartas ni lo subas a repositorios.
